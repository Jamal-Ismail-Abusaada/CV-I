# CV-I — Personal Portfolio

موقع تعريفي ثابت مبني باستخدام HTML وCSS وBootstrap، يعرض التعريف الشخصي والخبرة والخدمات والأعمال وواجهة التواصل.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادماً محلياً من مجلد المشروع:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تنظيم الملفات

| الملف | المسؤولية |
| --- | --- |
| `index.html` | المحتوى، بنية الصفحة، وروابط الأقسام |
| `styl.css` | ألوان التصميم، القواعد المشتركة، الأزرار، وإمكانية الوصول |
| `css/navbar.css` | شريط التنقل |
| `css/hero.css` | المقدمة |
| `css/hub.css` | مؤشرات الخبرة |
| `css/herohub.css` | قسم التعريف |
| `css/my-servises.css` | بطاقات الخدمات |
| `css/img.css` | معرض الأعمال |
| `css/footer.css` | قسم التواصل |
| `js/navigation.js` | إغلاق قائمة الهاتف ونقل التركيز إلى القسم المختار |
| `favicon.svg` | أيقونة الموقع |
| `img/` | الصور المحلية |
| `bootstrap.min.css` | مكتبة خارجية؛ تجنّب تعديلها مباشرة |

تُحمّل ملفات CSS بروابط مباشرة، بعد Bootstrap ثم القواعد المشتركة. لا توجد حاجة إلى npm أو عملية بناء.

## نتائج المراجعة والتعديلات

- تصحيح `charset`، إزالة تعريف viewport المكرر الذي يمنع التكبير، وإغلاق حاوية التنقل.
- إزالة محاولة الوصول إلى `document.body` قبل إنشائه، وإلغاء تصغير الصفحة بواسطة `transform`.
- استبدال العروض والارتفاعات الثابتة والهوامش الكبيرة بتخطيط Grid مرن ونقاط توقف للجوال.
- إضافة `main`، عنوان رئيسي واحد، تسلسل عناوين مناسب، ورابط لتجاوز التنقل باستخدام لوحة المفاتيح.
- ربط التنقل بالأقسام، وتحويل أزرار التنقل إلى روابط ذات وجهات فعلية.
- إضافة أسماء لروابط الأيقونات، ونصوص بديلة وأبعاد للصور، وتحميل كسول للصور الثانوية.
- ربط تسميات النموذج بالحقول، واستخدام `tel` للهاتف، وإضافة أسماء الحقول والإكمال التلقائي.
- توحيد الألوان والأزرار، وإضافة حالة تركيز واضحة واحترام تفضيل تقليل الحركة.

## ما يحتاج إلى محتوى أو تكامل

- زر تنزيل السيرة معطّل لعدم وجود ملف CV. عند توفيره، استبدل الزر برابط إلى الملف مع خاصية `download`.
- نموذج التواصل واجهة معاينة وزر الإرسال معطّل. يلزم ربطه بخدمة إرسال، مع معالجة النجاح والأخطاء، قبل تفعيله.
- روابط الشبكات الاجتماعية تتجه إلى الصفحات العامة؛ استبدلها بروابط الحسابات الشخصية.
- نصوص Lorem ipsum وبعض إحصاءات الخبرة ورقم الهاتف محتوى تجريبي يحتاج إلى مراجعة صاحب الموقع.
- قائمة الجوال تعتمد على Bootstrap JavaScript المحمّل من CDN، ولذلك تحتاج إلى اتصال بالإنترنت. يمكن استضافة نسخة مطابقة محلياً للعمل دون اتصال.

إرشادات إمكانية الوصول المستخدمة في المراجعة: [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md).

## مراجعة التجاوب والتناسق

تم تحسين التصميم والمسافات عبر عرض محتوى موحّد أقصاه 1180 بكسل، ومسافات أقسام متدرجة بين 48 و88 بكسل، وحجم ومسافة موحّدين لعناوين الأقسام. المقدمة تعرض النص أولاً والصورة بجانبه على الكمبيوتر وأسفله على الهاتف. بطاقات الخدمات بمحاذاة نص واضحة وأزرار مصطفّة، ومعرض الأعمال يستخدم إطارات متساوية بنسبة 4:3 مع `object-fit: contain` لإظهار الصور كاملة دون تشويه أو قص.

لوحة الألوان موحّدة في متغيرات `styl.css`: خلفية بيضاء `#ffffff`، أقسام فاتحة `#f0f6f8`، بطاقات بيضاء، لون تمييز تركوازي عميق `#077580`، عناوين كحلية `#14263d`، ونصوص ثانوية `#475569`. نموذج التواصل والقائمة يتبعان المظهر الفاتح نفسه. اجتازت 48 حالة نصية مفحوصة قياس التباين (4.5:1 للنص العادي و3:1 للنص الكبير)، مع إعادة فحص عدم تجاوز العرض عند 320 و390 و820 و1440 بكسل.

تم التحقق باستخدام Playwright وMicrosoft Edge على العروض: 320، 375، 390، 480، 576، 640، 768، 820، 991، 992، 1024، 1280، 1440، 1920 بكسل. لم يظهر تجاوز أفقي على هذه المقاسات.

- الهوامش والمسافات والخطوط تتدرج مع عرض الشاشة.
- مؤشرات الخبرة تظهر في عمودين على الهاتف، والخدمات في عمود واحد للهاتف وعمودين للتابلت وثلاثة للكمبيوتر.
- معرض الأعمال يتدرج من عمود واحد إلى عمودين ثم ثلاثة، مع الحفاظ على نسب الصور الأصلية.
- روابط الأقسام تستخدم تمريراً سلساً، ويُلغى عند تفعيل تفضيل تقليل الحركة.
- تم التحقق من فتح قائمة الهاتف وإغلاقها بعد التنقل، ونقل التركيز إلى القسم، وصلاحية حقل البريد، وتحميل الصور الثماني، وعدم ظهور أخطاء JavaScript خلال الفحص.
- صور الأعمال الأصلية صغيرة (بعرض يقارب 220 بكسل)؛ تحسين حدتها على الشاشات الكبيرة يحتاج إلى نسخ أعلى دقة.

لقطات المراجعة موجودة في `output/playwright/after-mobile.png` و`after-tablet.png` و`after-desktop.png`. يمكن إعادة الفحص بعد تشغيل الخادم المحلي:

```sh
playwright-cli.cmd -s=cv-review open http://127.0.0.1:8000 --browser msedge
playwright-cli.cmd -s=cv-review run-code --filename output/playwright/verify.js
```

هذه النتائج تخص Edge وأحجام نافذته؛ لا تعادل فحص أجهزة فعلية أو Safari وFirefox.
